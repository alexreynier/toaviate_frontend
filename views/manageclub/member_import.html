What the file needs
  • An email address and a first and last name for each person.
  • If you have them: membership type, the dates their current membership starts and ends, the day they first joined, date of birth.
  • Any other columns are ignored. Nothing is saved until you press Import at the end.
Coming from Excel, Numbers or Google Sheets?
  • Excel: File → Save As → “CSV UTF-8 (Comma delimited)”.
  • Google Sheets: File → Download → Comma-separated values.
  • Numbers: File → Export To → CSV.
