How it works

  1. Copy the embed code above and paste it into your website's HTML
  2. The widget automatically loads your club's purchasable experiences
  3. Customers can browse, select, and pay — all within the widget
  4. Payments go to your Stripe account; vouchers and invoices are created automatically
  5. Monitor all widget purchases from the Purchases tab
Regenerate the token? The old embed code stops working immediately — you'll need to update it on your website.
Disable the voucher widget? It will immediately stop working on any website using the embed code.
